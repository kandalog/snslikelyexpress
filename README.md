いいね

## ローカルで試してみたい方へ

_手順_

1. `git clone <リポジトリ>`
2. `cd <リポジトリ>`
3. `npm install`
4. `server.js`の DB 接続部の URL を自分で作成した MONGODB に切り替える
5. `npm start`
6. `http://localhost:3000`
